# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

页眉导航挂两个页面：**总表**（登记与结论）和**速率专页**（看拱顶是不是越挤越快）。

## 速率专页

- **上块 · 拖取点窗口**：在断面时间轴上拖动框选取点窗口，可拖边缘微调、可整体平移；保存按断面持久化。
- **中块 · 各断面拟合速率与样本点**：按断面列出拟合速率（mm/周）、样本点明细与拟合线小图。
- **下块 · 计算口径**：页面内写清取点、拟合、空值、并发与权限口径。

计算口径（与页面下块一致）：

- 样本只取状态为「已完成」（已办结）的测点，待认领（pending）不进样本；
- 以办结时刻 `processed_at` 为横轴、收敛值 `delta_mm` 为纵轴，做最小二乘一元线性回归，斜率即速率，单位 mm/周；
- 只统计办结时刻落在窗口内（含端点）的点；未设窗口时用该断面全部已办结点；
- 窗口内样本不足 2 个或时刻全相同时速率为空；
- 窗口保存带版本号（乐观锁）：两人几乎同时改同一断面窗口只有一笔生效，另一笔收到 `409`，需刷新重试。

### 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/rates` | 按断面返回窗口、样本点、拟合速率（登录即可，含巡检员） |
| PUT | `/api/sections/<桩号>/window` | 保存断面窗口（仅测量员）；body 为 `start_at`/`end_at`/`version`，版本不符返回 409 |

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

