# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

页眉有两个页签：**读数总表**与**周进尺速率**。速率专页用来判断“拱顶是不是越挤越快”。

## 周进尺速率专页

- **上块·取点窗口**：按断面拖拽时间窗两端（或键盘左右键），松手即按该窗口重新拟合并落库。仅测量员可调；巡检员只读，手柄禁用、接口也拒绝（403），不能改也不能报。
- **中块·按断面列出拟合速率与样本点**：每个断面给出最小二乘斜率（mm/周）与上升/走平/回落/空状态、样本数、R²，并画散点（窗口内蓝色实心、窗口外灰色空心）与拟合直线，附办结读数明细表。速率只在本专页呈现，**读数总表不加斜率列**。
- **下块·口径**：页面写清取数与拟合口径。

口径：横轴取**办结时刻**（不是登记时刻）；**只有已办结（done）且有办结时刻的读数进样本**，待认领/未办结点一律排除；按断面对窗口内样本做一元最小二乘 `y = a + b·x`（x 以周计），b 即周进尺速率（mm/周）；窗口内有效样本不足 2 个时记“空”，不编造数字。把窗口缩到样本之外，速率变为走平/空。

并发：窗口按断面唯一，带 `version` 乐观锁（行锁 + 原子条件更新 + 唯一约束）。两人几乎同时改同一断面只保留先落库的一笔，落败方收到 409 与服务器当前那一笔并自动对齐。

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/rate/sections` | 登录 | 按断面返回域、窗口、拟合速率、拟合线段与样本点 |
| PUT | `/api/rate/window` | 仅测量员 | 保存取点窗口，body 带 `version`；并发落败返回 409 |

拟合纯逻辑单测（仅标准库）：`python3 backend/test_rates.py`。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
